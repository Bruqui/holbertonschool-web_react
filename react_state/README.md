# React state

Suite du projet `react_styling`. Le dashboard est modulaire et stylé ; il gagne maintenant de la
logique et de l'état local.

| Tâche | Sujet |
| --- | --- |
| [task_0](task_0) | Adding a local state for notifications — App ouvre et ferme le tiroir de notifications |
| [task_1](task_1) | Controlled components and state callback — formulaire de login contrôlé, bouton activé à la validation |

## Prérequis

- Node 20.x, npm 10.x
- Jest 29.7.0

## Usage

```bash
cd task_0/dashboard
npm install
npm run dev     # serveur de développement Vite
npm run build   # build de production
npm test        # Jest
npm run lint    # ESLint
```
